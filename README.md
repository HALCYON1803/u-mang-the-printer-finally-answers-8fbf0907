# The Printer Finally Answers

The office printer's funny comeback to paper jams, error codes and thumps —
in the printer's own voice: weary, literal, faintly passive-aggressive, with
the flat logic of a device that has counted every sheet it ever fed.

`main.ts` (run with node22) writes exactly one line to `/output/entry.txt`:

> Sheet 12,847 jammed — the first one in 12,846 — and you hit me for it.

12,846 perfect sheets, one jam, and the human's answer is a thump. The
printer keeps count. We don't.
